# TensorIR Maintainers

## Maintainers

| GitHub handle | Role |
| --- | --- |
| [@sfawzy-nv](https://github.com/sfawzy-nv) | Project maintainer and CODEOWNER |

Maintainers review changes, triage issues, manage releases, and enforce the
project's contribution and security policies.

## Escalation

For ordinary project matters, open a
[GitHub issue](https://github.com/NVIDIA/tensor-ir/issues) and request
maintainer attention. For conduct concerns, use the contact in
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). For security vulnerabilities, use
the private NVIDIA PSIRT process in [SECURITY.md](SECURITY.md), never a public
issue.
