# TensorIR Support

## Support level

TensorIR is experimental open-source software under active development. It is
provided without a service level agreement, guaranteed response time, or
backward-compatibility commitment.

## Getting help

Use [GitHub Issues](https://github.com/NVIDIA/tensor-ir/issues) for bug reports,
feature requests, documentation requests, and usage questions. Search existing
issues before creating a new one and use the appropriate issue form.

For effective troubleshooting, include the TensorIR revision, CUDA Toolkit and
driver versions, GPU model, host platform, build configuration, full logs, and
a minimal reproducer when possible.

## Security

Do not report security vulnerabilities through GitHub. Use the private NVIDIA
PSIRT channels documented in [SECURITY.md](SECURITY.md).
